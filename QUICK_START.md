# 🚀 Quick Start Guide - BreathFlow Enhanced

## Prerequisites

- Node.js installed
- Expo CLI installed (`npm install -g expo-cli`)
- iOS Simulator or Android Emulator (or Expo Go app on phone)

## Installation

All dependencies are already installed! Just run:

```bash
npm start
```

Or for specific platforms:

```bash
npm run android  # For Android
npm run ios      # For iOS
npm run web      # For Web
```

## First Time Setup

1. **Launch the app** - Run `npm start`
2. **Onboarding** - Complete the 5-screen tutorial (or skip)
3. **Home Screen** - You're ready to breathe!

## Feature Tour

### 🏠 Home Screen

- **Stats Card** - View your progress (sessions, minutes, streak)
- **Quick Actions** - Access Achievements and Settings
- **Pattern Selection** - Choose from 7 presets or create custom
- **Theme Selection** - Pick your visual theme
- **Begin Session** - Start breathing!

### 🧘 Breathing Session

1. Select a pattern
2. Tap "Begin Session"
3. Follow the breathing circle:
   - **Expanding** = Breathe In
   - **Static** = Hold
   - **Contracting** = Breathe Out
4. Complete all cycles
5. Rate your mood (optional)
6. Add notes (optional)

### ✏️ Create Custom Pattern

1. Tap "+ Create Custom"
2. Name your pattern
3. Set durations (inhale, hold, exhale, hold)
4. Set number of cycles
5. Review preview
6. Save!

### 🏆 View Achievements

1. Tap "Achievements" button
2. See 11 unlockable badges
3. Track your progress
4. Unlock achievements by:
   - Completing sessions
   - Building streaks
   - Trying different times of day
   - Exploring all patterns

### ⚙️ Customize Settings

1. Tap "Settings" button
2. Adjust:
   - Vibration intensity
   - Animation style
   - Background sounds
   - Sleep mode
   - Focus mode
   - Daily reminders

### 📖 View History

1. Tap "View History"
2. See all past sessions
3. View mood and notes
4. Track patterns over time

## Default Breathing Patterns

1. **4-7-8 Relaxing** - Best for sleep & anxiety

   - 4s in → 7s hold → 8s out × 4 cycles

2. **Box Breathing** - Navy SEAL technique

   - 4s in → 4s hold → 4s out → 4s hold × 5 cycles

3. **Deep Calm** - Meditation

   - 5s in → 5s hold → 5s out × 6 cycles

4. **Quick Relief** - Fast stress relief

   - 3s in → 6s out × 8 cycles

5. **Coherent Breathing** - Heart rate balance

   - 5s in → 5s out × 10 cycles

6. **Energy Boost** - Morning energizer

   - 2s in → 2s hold → 4s out × 10 cycles

7. **Sleep Inducer** - Bedtime relaxation
   - 4s in → 4s hold → 8s out → 2s hold × 6 cycles

## Tips for Best Experience

### 🌅 Morning Routine

- Use "Energy Boost" pattern
- 2-3 minute quick session
- Build your daily streak

### 😰 Stress Relief

- Use "Box Breathing" or "Quick Relief"
- Focus on the animation
- Take 5 minutes to reset

### 😴 Better Sleep

- Use "4-7-8 Relaxing" or "Sleep Inducer"
- Enable Sleep Mode in settings
- Practice before bed

### 🧘 Meditation

- Use "Deep Calm" or "Coherent Breathing"
- Enable Focus Mode for minimal distractions
- Add optional background sounds

## Achievement Guide

Quick ways to unlock achievements:

- **First Breath** - Complete any session
- **3 Day Streak** - Practice 3 days in a row
- **Getting Started** - Complete 10 sessions total
- **Night Owl** - Do a session after 10 PM
- **Early Bird** - Do a session before 6 AM
- **Pattern Explorer** - Try all 7 preset patterns

## Troubleshooting

### App won't start

```bash
npm install
npm start
```

### Patterns not saving

- Check storage permissions
- Restart the app
- Clear cache: `expo start -c`

### Achievements not unlocking

- Complete full sessions (don't exit early)
- Check progress in Achievements screen
- Data persists across app restarts
