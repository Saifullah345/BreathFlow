# BreathFlow - Guided Breathing App

A beautiful, offline breathing exercise app with relaxing animations and haptic feedback.

## Features

✨ **5 Breathing Patterns**
- 4-7-8 Relaxing
- Box Breathing
- Deep Calm
- Quick Relief
- Coherent Breathing

🎨 **5 Visual Themes**
- Ocean (Blue)
- Forest (Green)
- Sunset (Orange)
- Lavender (Purple)
- Minimal (Gray)

📊 **Progress Tracking**
- Total sessions completed
- Total minutes practiced
- Current daily streak
- Complete session history

📳 **Haptic Feedback**
- Synced with breath cycles
- Different vibrations for inhale/exhale/hold

🎯 **100% Offline**
- No internet required
- No API calls
- All data stored locally

## Getting Started

### Install dependencies
```bash
npm install
```

### Start the app
```bash
npm start
```

### Run on platforms
```bash
npm run android
npm run ios
npm run web
```

## How to Use

1. **Choose a Pattern**: Select from 5 pre-configured breathing patterns
2. **Select a Theme**: Pick your preferred visual theme (ocean, forest, sunset, etc.)
3. **Start Session**: Tap "Begin Session" to start
4. **Follow the Circle**: Breathe in as the circle expands, out as it contracts
5. **Feel the Feedback**: Experience gentle vibrations synced with your breath
6. **Track Progress**: View your stats and session history
